

# GitHub Workflow & Deployment
All AI agents modifying this repository MUST adhere to the following workflow:
1. **GitHub Issues**: Create an issue on GitHub for every task (bug fix, enhancement, new feature) before beginning implementation.
2. **Pull Requests**: Do not commit directly to `main`. Create a feature branch and manage deployments exclusively through Pull Requests.
3. **Issue Linking**: Always mention the relevant issue number in the PR description (e.g., "Closes #123").
